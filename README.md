# Aividia Telegram Channel Publisher

Automated Telegram Channel Content Publisher for Aividia (aividia.ir).

## Workflows
- **Telegram Automated Channel Poster:** Publishes scheduled health tips, infographics, and AI clinical summaries.
- **Telegram Sitemap Blog Post Publisher:** Continuously monitors the live sitemap and introduces new blog articles.

## Security
- Bot tokens and channel IDs are strictly loaded from GitHub Secrets (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`).
- No private patient data, credentials, or proprietary backend files are included.
